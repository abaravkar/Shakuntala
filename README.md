# Shakuntala project workspace

The runnable Laravel/MySQL/Node project is in [app](app/README.md).

Local preview: http://127.0.0.1:8000

```powershell
cd F:\laravel\Shakuntala\app
php artisan serve --host=127.0.0.1 --port=8000
```

The original `Shakuntala_Full_Multilingual_Website.zip` is unchanged. `reference/shakuntala-website` holds its extracted contents. Root `.cjs` files record the initial import and page generation; do not rerun them after editing the application, because they overwrite generated source files.

See `app/README.md` for administrator setup, MySQL settings, development commands and pending integrations.
